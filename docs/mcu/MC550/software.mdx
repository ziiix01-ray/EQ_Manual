    ## 1. 軟件的構成和運作
   
         本章對軟件的構成和運作進行說明。												
																										
    ###1.1　固件和應用程序													
	　     ＭＣ－５５０軟件，如表２．１所表述，是由最初就被組合在目標機上的固件												
	      （系統軟件）和用戶製作的應用程序（ＢＢＰ）所構成的。固件是為了讓本系統運作												
	       的基本軟件，應用程序是指控制外部機器所需的軟件（控制組件、控制模塊）。												
													
	　     固件和應用程序，全部實行版本管理，包括它們的構成要素即任務和程序庫。												
	       用戶可以確認被組合在目標機上的所有軟件的版本。												
													
	　     另外在咨詢的時候，請一起告知固件以及應用程序的統括版本。這樣												
	       我們可以通過ＯＰＵ或者專用系統來確認版本信息。

    ![表2-1圖](/img/mcu/t21.png)

    ###1.2　處理的實行											
	　     隨著目標系統的電源投入，進度器會自動地開始實行處理。										
	       關於進度器的起動週期以及方法、可以根據設定方法圖表來進行設定。										
											
	　     標准任務可以通過在設定方法圖表進行定義名登錄，來控制處理的實行。										
	       請根據系統構成選擇要實行的標准任務。										
	      （詳細內容，請參照「４．應用程序的製作」。）										
	　     控制組件也同樣可通過在設定方法圖表登錄定義名，來控制處理的實行。										
	       請定義想要實行的控制組件名。										
	　     如果控制模塊在控制組件，控制芯片在控制組件或者控制										
	       組模塊中使用時，處理功能會被呼出進行實行。										
											
											
     ###1.3　實行的時機											
	　     本系統的軟件、通過專用多任務ＯＳ（最快優先度處理方式）可以同時										
	       實行幾個任務。可以把實行時機、設定為超高速、高速、中速、低速、										
	       基本以及帶時間表登記6個種類、通常使用高速、中速、低速以及基本處理。										
	       關於各任務的優先順序、用設定方法設定的任務編號小的排在前面。										
	       處理的分配、請讓起動週期短的任務的優先順序排在前面來進行分配。										
											
	　     但是，任務是指設定方法設定上的任務，1個任務最多包括2種處理。

    ![任務實行的概念圖](/img/mcu/p2.1.png)

      ###1.4　輸入輸出處理														
	　     應用程序（ＢＢＰ）通常被分配在高速任務（ＩＤ：１～１９９）和低速任務（ＩＤ：２０１～３９９）上。													
	       因此所有使用的外部數據（ＳＣＣ的Ｉ／Ｆ數據、Ｉ／Ｏ、通信數據等）													
	       會在高速ＢＢＰ的實行前後更新。													
	　     使用單元之間同期選擇的時候、對外部數據進行單元間的低速傳送的情況下													
	      （注）、數據會在低速ＢＢＰ的實行前後更新（※１）。

           #####※１關於低速傳送的使用方法，請參考５．參數的設定　表５．２　Ｉ／Ｏ參數一覽　區分：MM-Link２；										
　　　　           關於單元間數據的輸入輸出數據時機，請參照附．５　單元間同期輸入輸出數據時機。

    ### 8.1 錯誤編碼與檢出標準
    本系統根據錯誤嚴重程度分為四個等級：
    1. **重大故障**：系統強制停機。
    2. **輕微故障**：系統繼續運行但需注意。
    3. **警報**：提示性質。
    4. **無檢出**：不作紀錄。

    ### 8.2 錯誤發生時的動作 (表 8.1)
    | 裝置 | 動作說明 |
    | :--- | :--- |
    | **7SEG-LED** | 顯示錯誤碼。多個錯誤時每隔 1 秒循環顯示。正常時顯示 **00** 閃爍。 |
    | **OPU 面板** | 顯示錯誤碼及輔助編碼。僅顯示最初檢出的錯誤。 |
    | **通訊網路** | 透過 CC-Link 或 DeviceNet 將錯誤資訊傳送至上位機。 |

    ### 8.3 錯誤復位 (Reset)
    *   **OPU**：按下 **STOP (RESET)** 鍵。
    *   **通訊指令**：在系統預約的復位領域寫入「1」持續至少 1 秒。

    ---

    ### 8.5 錯誤編碼一覽表 (精簡版)
    > 註：編碼格式為「錯誤碼」.「*輔助編碼*」

    | 編碼 | 名稱 | 等級 | 詳細內容與處置方法 |
    | :--- | :--- | :--- | :--- |
    | **13** | 電池電壓低下 | 重大 | 電池電壓低於 2.65V。**請更換電池**。 |
    | **14/15** | 風扇異常 | 重大 | MCU 機架冷卻風扇停止。檢查電纜或更換風扇。 |
    | **22** | 總線訪問異常 | 重大 | 對 SCC/HMAN 卡訪問失敗。檢查插槽連接。 |
    | **2E** | 看門狗(WD)異常 | 重大 | MCC 控制卡 CPU 誤動作。需更換板卡。 |
    | **36** | OPU 通訊異常 | 重大 | 通訊重試超過規定值。檢查序列電纜。 |
    | **41~4F** | **[CC-Link 相關]** | 重大 | 包含初始化失敗、站號設定錯誤、數據鏈路中斷等。 |
    | **51~55** | **[DeviceNet 相關]** | 重大 | 包含 MAC ID 重複、波特率錯誤、CAN 通訊故障等。 |
    | **62/63** | 演算錯誤 | 輕微 | 浮點數 0 除算或無效運算。檢查 BBP 程式邏輯。 |
    | **82** | 任務超越執行 | 輕微 | Task 實行週期不足。請延長系統週期設定。 |
    | **D1~D8** | **[SCC 伺服異常]** | 重大 | 伺服軸超速、PG 斷線、過電流、過電壓、欠相。 |
    | **E1~E7** | **[HMAN 從動異常]** | 重大 | 附屬設備 (如變頻器) 通訊或硬體異常。 |
