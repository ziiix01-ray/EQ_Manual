    ## 2. 系統組態 (System Configuration)

    本節說明 MC-550 System MX 的系統配置及其注意事項。

    ### 2.1 系統架構概要
    MC-550 系統主要設計用於控制各類生產線系統，包括金屬加工、紙張與薄膜處理以及印刷系統。

    #### 2.1.1 系統配置圖
    下圖展示了 MC-550 與各單元（如 PLC、操作單元、驅動器等）的連接架構：

    ![MC550系統配置圖](/img/mcu/mc550_config.jpg)
    *圖 2.1.1：系統組態示意圖*

    ---

    ### 2.1.2 系統組態注意事項
    在配置 MC-550 系統時，請務必參考以下各單元的連接數量與規格限制。

    #### 2.1.2.1 MC-550 單元構成
    *   **核心組成**：由一個**主控制單元 (MCU)** 與多個**功率放大單元 (PAU)** 組成。
    *   **擴充能力**：一個 MCU 最多可透過 PWM 電纜連接 **8 個 PAU**，實現高達 **8 軸** 的完全同步驅動控制。

    #### 2.1.2.2 外部設備連接能力 (Table 2.1.1)
    多種外部設備可連接至 MC-550 單元，詳細規格如下表：

    | 可連接設備 | 數量限制 | 連接點 | 介面規格 |
    | :--- | :--- | :--- | :--- |
    | **操作面板 (OPU)** | 1 台 | MCU 序列埠 | RS232C |
    | **開發與調試用 PC (PC-AT)** | 1 台 | MCU 序列埠 | RS232C |
    | **變頻器 (Inverters)** | 最多 7 台 | MCU 擴充卡 (HMAN2) | HMAN (RS485) |
    | **遠端 I/O 單元 (Remote I/O)** | 最多 7 台 | MCU 擴充卡 (HMAN2) | HMAN (RS485) |

    :::note 註記
    1. 支援 Vector Inverter AF-1800α 等型號。
    2. 支援 Driver I/O2 Unit (Remote I/O Unit) 等型號。
    :::

    #### 2.1.2.3 與 PLC 的通訊介面
    *   **連接方式**：MC-550 可使用 **CC-Link 擴充卡** 連接至 PLC。
    *   **站號容量**：單一 CC-Link 主站 (Master Station) 最多可連結 **16 台 MC-550 單元**。

    ## 3. 一般規格 (環境規格)
    以下為 MC-550 System MX 的一般環境操作規範：

    | 項目 | 規格內容 |
    | :--- | :--- |
    | **操作環境溫度** | 0 ~ 50℃ |
    | **儲存環境溫度** | －10 ~ 65℃ |
    | **操作環境濕度** | 30 – 90% RH (無結露) |
    | **儲存環境濕度** | 30 – 90% RH (無結露) |
    | **耐振動** | 符合 JIS C 0911 (低於 0.6G) |
    | **耐衝擊** | 符合 JIS C 0912 |
    | **使用環境** | 室內 (無腐蝕性、有毒或易燃氣體，無塵及無油霧環境) |
    | **耐壓測試** | 1500 VAC 持續一分鐘 |
    | **絕緣電阻** | 5MΩ 或更高 (經 500VDC 絕緣測試計) |
    | **抗雜訊能力** | 1500Vp-p 脈衝，上升斜率 1ns，脈衝寬度 1μs |
    | **接地等級** | D 類接地 (接地電阻小於 100Ω) |
    | **操作高度** | 海拔 1000 公尺以下 |

    ### 3.2 主控制卡 (MCC) 詳細性能
    主控卡（MCC）是一款SH-4（167MHz）CPU卡，能夠高速運作。透過伺服控制卡
   （SCC）介面連接，每個MCC可同步控制多達8軸驅動器。此外，MCC還可以透過序列介面
    、PC/104匯流排介面或HMAN2介面與各種類型的設備連接。
    該系統整合了韌體（系統軟體）和應用軟體（BBP） ¹，以實現簡單的系統配置並執行
    各種高速控制操作功能。此MCC控制卡用於控制各種線路控制應用。

    註： 1）	請參閱 MC-550（System MX）軟體說明手冊

    #### 3.2.3 MCC 名稱及指示器和開關的設置

    MCC 包含大量的硬體跳線 (JP1 ~ JP41)，用於配置系統底層行為：
    - **JP1/JP2**：接地選擇 (5VGND 與 ±12VGND 連結)。
    - **JP8/JP11**：Flash ROM 類型選擇 (32Mbit 或 16Mbit)。
    - **JP15~JP22**：Z相脈衝入力電壓選擇 (12V 或 24V)。
    - **JP23**：異常時 DO 狀態保持或清除。

    ## 4.主控制單元 (MCU) 硬體規格

    | 項目 | 規格描述 |
    | :--- | :--- |
    | **電源需求 (電壓)** | 85 – 265 VAC，單相 |
    | **電源需求 (頻率)** | 47 ~ 63 Hz |
    | **功耗** | 低於 400 VA |
    | **允許瞬時停電時間** | 10 ms 以內 (低於 10ms 不視為停電) |
    | **運算能力** | 內建浮點運算處理器 (1.1GFLOPS)<br/>內建 RISC CPU (300 MIPS) |
    | **I/O 介面** | AD 輸入：16 通道 (若安裝 8 個 SCC) |
    | **日曆/定時器 IC** | 內建 |
    | **程式記憶體** | Flash memory (非揮發性) |
    | **參數記憶體** | PEROM (非揮發性) |
    | **運算輸出數據** | SDRAM 或 電池備援記憶體 |
